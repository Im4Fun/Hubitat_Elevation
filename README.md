# Hubitat Elevation — Custom Drivers

A collection of custom Groovy drivers for the [Hubitat Elevation](https://hubitat.com) home automation platform.

---

## Drivers

| Driver | Description |
|---|---|
| SMHI Weather Driver | Weather data from SMHI (Swedish Meteorological and Hydrological Institute) |
| Schneider WDE002348 Switch | Driver for Schneider Electric WDE002348 switch |
| Schneider WDE002182 Power Outlet | Driver for Schneider Electric WDE002182 power outlet |
| Crime Monitor SE | Monitors crime statistics in Sweden |
| Tibber Smart Driver | Integration with Tibber smart electricity |
| Xiaomi Aqara Cube | Driver for Xiaomi Aqara Cube controller |
| Aeotec HEM 8 Driver | Driver for Aeotec Home Energy Meter 8 |
| Unified Energy Child Device | Child device driver for unified energy monitoring |
| Unified Energy Meters and Estimation | Energy meters and cost estimation |
| INNR Colour RGBW Bulb | Driver for INNR colour RGBW smart bulbs |
| INNR AE264 RB247T Zigbee | Driver for INNR AE264/RB247T Zigbee devices |

---

## Installation

1. In Hubitat, go to **Drivers Code** → **New Driver**
2. Copy and paste the contents of the desired `.groovy` file
3. Click **Save**
4. The driver is now available when adding or editing a device
